## Exercitiul 1

PyMC: 4 lanturi, 1000 tune, 2000 draws.

a) Distributia a posteriori a lui N are cele mai probabile valori in jur de 70-75, dar se intinde mult spre 200.

b) Media = 103.74, Mediana = 97.0, HDI 95% = [45.0, 181.0].
Estimarea clasica este 75.0. Media este mai mare decat 75 pentru ca distributia are o coada lunga spre valori mari (avem putine date si multa incertitudine).

c) Probabilitatea ca N > 100 este 0.465 (46.5%).

d) Distributia lui N arata cat ar putea fi populatia totala (intre 20 si 200). Distributia predictiva arata cate animale marcate am putea prinde la o noua captura de 15 animale (intre 0 si 15), incluzand si aleatoriul noii capturi.
